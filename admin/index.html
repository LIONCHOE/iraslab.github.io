GitHub 연결

iraslab/iraslab.github.io 저장소에 Contents: Read and write 권한이 있는 fine-grained personal access token을 입력하세요. 이 페이지는 토큰을 저장하지 않습니다.

관리자 계정에서 토큰을 발급하고, 저장소 접근 대상을 이 저장소 하나로 제한하세요.

업로드할 변경사항 없음

수정·추가·삭제·이동은 임시 반영됩니다. 상단의 변경사항 업로드를 누르면 한 번에 게시됩니다.
