GitHub 연결

위에 표시된 저장소에 Contents: Read and write 권한이 있는 fine-grained personal access token을 입력하세요. 이 페이지는 토큰을 저장하지 않습니다.

관리자 계정에서 토큰을 발급하고, 저장소 접근 대상을 이 저장소 하나로 제한하세요.

업로드할 변경사항 없음

수정·추가·삭제·이동은 임시 반영됩니다. 상단의 변경사항 업로드를 누르면 한 번에 게시됩니다.

논문 정보 일괄 반영

제목·분류·연도와 기존 서지 정보가 일치하는 항목의 제목·서지 정보·원문 URL을 검토한 뒤 임시 반영합니다. 기존 URL 목록도 사용할 수 있습니다.

목록을 선택하면 일치 항목과 변경 내용을 확인할 수 있습니다.
